VIPV Logistics Routing — Literature Audit Tables

Supplementary material to the literature review chapter of the thesis Probabilistic and online routing for vehicle-integrated photovoltaic logistics fleets. The four audits below cover ~120 implementation papers across the four subfields that bound the proposed work.

Audits

1. Deterministic E-VRPTW

Field-consensus matrix for electric vehicle routing with time windows. Covers 32 modelling features grouped into routing structure, time-window service constraints, energy and battery, charging operations, travel time, and objective form.

N = 40 implementation papers · 32 audited features · 4 foundation surveys

2. Routing under uncertainty

Field distribution across uncertainty sources, optimisation paradigms, uncertainty-set representations, recourse decisions, service-constraint handling, solver class, and evaluation protocol.

N = 50 implementation papers · 24 axes · 8 clusters

3. Online and rolling-horizon dispatch

Field distribution across the eleven Pillac et al. classification criteria plus EV-specific extensions, decision-framework type, anticipation strategy, recourse pattern, and online evaluation protocol.

N = 9 implementation papers · 25 axes · 8 clusters

4. VIPV physics and solar-irradiance uncertainty

Field distribution across solar resource components, atmospheric and clear-sky modelling, decomposition and tilt transposition, vehicle-specific physics, uncertainty representation, forecasting method, and evaluation.

N = 20 implementation papers · 28 axes · 8 clusters

How to read these tables

Every audit follows the same shape:

  • A field-consensus matrix reporting the share of papers that adopt each feature or methodological choice. Frequency tags use the same convention across audits — STANDARD (≥70%), COMMON variant (25–70%), UNCOMMON variant (5–20%), RARE (<5%), and OPEN FRONTIER (0%).
  • A spotlight set of 4–6 representative works for each subfield, with a one-line methodological position.
  • A gap statement identifying where the field has unaddressed combinations.

Source for each table: per-paper feature-signature audit conducted by the project author. Citations within each table use short author-year keys; the matching reference list in the thesis chapter resolves them in IEEE format.
